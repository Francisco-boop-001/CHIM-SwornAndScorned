# Sworn & Scorned 0.1.6 — PRE-ALPHA

The eight-NPC velvet rope has been removed. Select any number of known NPCs, or use **Select all**; **Clear selection** and a live count make the choice visible. **Save settings** still applies the selection and toggles. New arrivals need selecting later. More drama can mean more queued work and API charges; the worker still evaluates jobs serially.

**Recent activity** now shows timestamped, filtered plugin diagnostics from CHIM's log: settings, rejected forms, worker activity, safe failure codes, IDs and job duration. Plugin logs exclude dialogue, prompts, keys and provider bodies. CHIM retains control of its log levels, retention and server permissions.

**Director** reveals recorded issues and evidence. It cannot create drama from an empty journal; the page now explains that instead of staring back at you silently.

Jev remains optional and experimental, using CHIM OpenRouter credentials unless a dedicated encrypted override is saved. No new credential setup is required for this update. Existing cast choices are retained within their active playthrough; save again to expand them.

See [verification and limits](../docs/verification/dashboard-0.1.6.md). This release was tested on a disposable CHIM clone, including a 1,400-NPC browser save; gameplay and automatic MO2 transfer remain unverified.
